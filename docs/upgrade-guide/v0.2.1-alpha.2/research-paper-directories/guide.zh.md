# 科研论文目录命名

[English](guide.md) | 中文

## 变更

论文现在保存在 `<资料库>/papers/<论文名>/`，替代 `<资料库>/papers/<论文-id>/`。提供的论文名用于创建目录；文件名限制和重名后缀可能调整目录名。资料库独立记录已分配的目录名，不改变论文 ID。Topic Agent 使用已有的 `research_import_paper` 工具，并明确提供名称来创建子论文。

打开已有资料库时会自动移动 UUID 目录；[文档与运行数据布局](../research-content-storage/guide.zh.md)在 `agent-lib` 下写入当前版本 4 索引。论文 ID、会话身份、原文文件、笔记、提取正文、代码和附件均予以保留。包含 UUID 路径的脚本或外部链接需要更新。索引也保存论文会话的名称、置顶、归档状态和续读点。旧后端无法读取这些升级后的索引。

## 迁移

1. 停止所有使用该资料库的后端，并在启动更新后的后端前备份。不要让旧版与新版后端同时使用同一目录。
2. 按正常方式启动更新后的项目并打开科研资料库，无需手动重命名目录。
3. 将外部脚本和链接更新为 `research_context` 返回的论文当前 `directory` 或 `pdfPath`，不要根据论文 ID 拼接路径。前端与 Agent 工具会自动解析已分配的目录。
4. 确认 `agent-lib/library.json` 的 `version` 为 `4`，每篇论文有可读的 `folder`，且前端可打开 PDF 与笔记。使用多会话时，确认 Agent 栏可以切换会话，原会话仍可访问。备份保存在 `agent-lib/papers/<paper-id>/` 下。

若启动时报告目录迁移冲突，先停止后端，保留 `.transaction.json` 和报告中的两个目录。把无关的冲突目标目录移至其他位置，再启动更新后的后端继续恢复。不要删除事务记录或覆盖任一目录。需要使用旧版后端时，先恢复完整备份。
